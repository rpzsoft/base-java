# HTTP App server & client framework

Express.js inspired HTTP App server & a REST framework written in pure java + Netty as server.

Vite + vanilla TypeScript based client

---

# Technologies used for App Builder (this repo)

## Frontend

- Vite + vanilla TypeScript

## Backend

- Java 17
- Netty - for http server & client

**NO** Spring Framework, Hibernate dependencies

## Infrastructure (docker-compose.yml)

- PostgreSQL 17 
- Valkey 9 - sessions, queues, pub/sub, locks, rate limits
